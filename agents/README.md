## How To Use This

1. Read the relevant file before changing that area.
2. Update the relevant file when the change establishes durable knowledge.
3. Do not record guesses as facts. Mark unknowns as `TBD`.
4. If this folder is insufficient, consult `docs/`. `docs/PRD.md` is the product contract and its Authoritative Implementation Contract wins conflicts.
